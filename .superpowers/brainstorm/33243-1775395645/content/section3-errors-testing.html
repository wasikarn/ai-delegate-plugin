Error Handling — Graceful Degradation

Scenario Behaviour Fallback
Agent Teams unavailable
(feature flag off หรือ version เก่า)		 detect ก่อน spawn ด้วย TeamCreate try/except skip Path D → ส่ง disputed findings ตรง Adjudicator (current behavior)
Expert teammate crash
(timeout / error mid-debate)		 Lead detect teammate ไม่ respond ใน timeout treat finding เป็น unresolved → Adjudicator ตัดสิน
0 disputed findings
(consensus สูงมาก)		 DisputedFindingsBundle.disputed_findings == [] skip Path D entirely → output consensus findings directly
DebateResult parse failure
(malformed JSON from lead)		 warning logged, DebateResult.unresolved = all disputed Adjudicator รับทั้งหมด (safe over-escalation)
Lead session crash
(no session resumption in Agent Teams)		 outer timeout (300s) catches หลัง Agent tool timeout skip Path D → Adjudicator รับ disputed findings ตรง
Design principle: Path D failure ต้องไม่ทำให้ overall analysis crash — ทุก error path fallback ไป Adjudicator ซึ่งทำงานได้อยู่แล้ว

    debate = DebateTeamRunner.run(bundle) # Agent Teams

    verdict = Adjudicator.synthesize(bundle.disputed_findings) # fallback
