Debate Protocol — 1 Round Flow

🎯 Debate Lead
(Sonnet)
1. รับ DisputedFindingsBundle → สร้าง Agent Team (N experts)
2. Post แต่ละ disputed finding เป็น shared task → "ต้องการ verdict จาก expert ทุกคน"
👥 Expert Team
(kimi × N)
3. แต่ละ expert อ่าน disputed findings + original analysis ของ peers
4. ส่ง mailbox message: AGREE / CHALLENGE: [reason] / WITHDRAW
5. Experts เห็น peer messages → respond ครั้งเดียว (1 round)
🎯 Debate Lead
(collects)
6. รวบรวม responses → classify:
  • ≥80% AGREE → resolved_findings (ไม่ต้อง Adjudicator)
  • ยังแตกต่าง → unresolved_findings (ส่ง Adjudicator)
7. Return DebateResult JSON

Agent Definitions

📋 debate-lead.md
Role: Team Lead (Sonnet)
Tools: Agent, TaskCreate, TaskUpdate, SendMessage
Input: DisputedFindingsBundle JSON
Output: DebateResult JSON
สร้าง team → post tasks → collect responses → classify resolved/unresolved
📋 debate-expert.md
Role: Teammate (kimi-k2.5:cloud)
Tools: TaskList, TaskGet, SendMessage
Input: original analysis + peer findings
Output: AGREE/CHALLENGE/WITHDRAW per finding
อ่าน shared tasks → ส่ง position ผ่าน mailbox → ไม่ต้อง re-analyze code
Token cost estimate: debate-expert ไม่ต้อง re-read codebase (ใช้ original findings เป็น context) → cost ต่ำกว่า full re-analysis มาก · N=3 experts × 1 round ≈ ~$0.05-0.10 additional per debate
